LINE 門市營運平台

隱私權與個人資料使用說明

更新日期：2026 年 11 月 4 日

1. 收集的資料

使用 LINE 登入時，在您授權的範圍內取得 LINE 身分識別碼及顯示名稱；建立預約或號碼牌時記錄門市、日期、時段、選擇的服務、預約人數、狀態與系統操作時間。店家員工另可能提供管理帳號 Email、權限及店家聯絡資料。平台不要求顧客另填姓名或密碼。

2. 使用目的

資料僅用於辨識顧客身分、提供預約／取號／叫號、傳遞 LINE 官方帳號通知、處理取消與變更、維持系統安全，以及協助店家營運管理。系統不會出售個人資料給廣告商。

3. 誰可以存取

門市資料由該門市授權員工按角色讀取；平台管理者僅因維運、客服、安全或法定義務於必要範圍內處理。不同店家彼此無權直接讀取其他店家的顧客明細。LINE、Supabase 及網站託管商等服務供應商可能在提供服務時處理必要資料，並依其服務條款及適用法律提供保護。

4. LINE 身分與登入

本系統使用 LINE Login／LIFF 確認身分並使用 Supabase 維持工作階段。部分工作階段與介面偏好會儲存在瀏覽器中；使用者登出、清除網站資料、變更 LINE 帳號或授權失效時可能需要再次登入。

5. 資料保存及刪除

預約、取號與操作紀錄保存在資料庫，供提供服務、追查爭議及遵循相關保存義務使用。保存期間將考量業務所需與適用法令，不代表所有紀錄會自動在固定日期刪除。提出資料查詢、更正或刪除請求時，平台將核對身分並依適用規定處理；涉及法定保存義務的資料可能暫無法全部刪除。

6. 您的權利與申請方式

可透過平台 LINE 官方帳號提出個人資料查詢、更正、停止使用或刪除申請，請註明涉及的店家及預約／取號日期。請勿在 LINE 訊息中傳送密碼、Channel Secret、Access Token 或身分證影本。平台會先確認申請人身分，再由授權人員處理。

7. 資安措施

正式資料儲存於 Supabase，系統透過身分驗證、租戶隔離、角色權限及後端查核限制操作。LINE Channel Secret 與 Access Token 不公開放在 GitHub Pages；店家獨立 OA 憑證以 Supabase Vault 加密儲存。

8. 政策更新與聯絡

系統功能或法律要求改變時，本頁會更新並標示日期。正式商業服務開始前，平台需補充正式經營者的法定識別及聯絡資料。對個資處理有疑問，請由平台 LINE 官方帳號聯絡。
