商家負責人操作

先建立帳號，再完成店家設定

  1. 開啟「店家註冊」。建議直接選「使用 Google 帳號繼續」，不需要重新設定密碼。

需要準備① Channel secret（頻道驗證金鑰）② Channel access token（長效存取權杖）

Channel ID 會自動辨識；單純發送 LINE 通知，不需要設定 LIFF ID。

  1. 開啟官方帳號管理後台。前往 LINE 官方帳號管理後台，選擇店家的帳號；尚未申請的店家，請先建立官方帳號。
  2. 啟用 Messaging API。在官方帳號的「設定 → Messaging API」啟用功能，選擇或建立 Provider。已有官方帳號不需要重新申請。
  3. 複製 Channel secret。前往 LINE Developers Console，選擇對應的 Messaging API 頻道，在「Basic settings」中複製。
  4. 取得 Channel access token。切換到「Messaging API」頁籤，在「Channel access token (long-lived)」按「Issue」取得憑證。
  5. 回到排隊怪獸完成連接。進入「設定 → LINE 官方帳號串接」，填入兩項憑證，按「驗證並連接 Messaging API」。完成後請用真實手機確認顧客身分配對及預約、取號通知是否送達。
進階選用：店家自己的 LINE Login／LIFF

如果希望顧客以店家 Provider 的 LINE 身分登入，才需要另外建立 LINE Login 頻道與 LIFF App。不同 Provider 的 LINE User ID 不會自動相同，必須完成身分配對。

07

線上點餐與取餐怎麼設定？

沿用既有的菜單，再決定是否開放指定取餐時間。店員從「取餐訂單」處理每筆訂單。

01

開啟線上點餐

管理者進入「設定」，在「線上點餐與取餐進度」開啟服務；餐點直接使用原本的「菜單與服務」，不必另外建立一份。

02

決定取餐方式與時段

選擇「僅立即取餐」、「可選立即或預約取餐」或「必須選擇取餐時間」，再設定時段間隔、容量與至少提前幾分鐘下單。

03

分享點餐入口

啟用服務後，複製設定畫面提供的店家專屬點餐連結，讓顧客以手機選餐並送出訂單。

04

店員依取餐時間處理

在側邊的「取餐訂單」查看待接單、已接單與已完成待取的訂單；可執行「接單」、「已完成待取」或「取消訂單」，按錯時仍可更正狀態。

前往設定 → 菜單與點餐前往取餐訂單 →
顧客下單後有 15 秒可以取消；倒數結束才會交由店家接單。取餐時間與製作時間應依店家實際營業安排設定。

店家最常遇到的問題

不用翻技術文件；依實際操作情境查找。

我沒有自己的 LINE 官方帳號，也能讓顧客預約嗎？

可以。完成註冊及門市基本設定後，可使用平台共用 LINE 官方帳號接待顧客。顧客可從平台的店家搜尋入口，或直接掃店家專屬 QR Code／點分享網址進行預約或取號。

預約已報到，為什麼沒有自動進入叫號？

預約與取號預設為獨立流程。沒有啟用場次連動時，報到只會更新預約狀態；若已啟用「預約報到後自動加入場次叫號」，則會自動建立對應場次票券。

客人過號、按錯，或要恢復候位怎麼辦？

到「叫號管理」找到該號碼牌，依目前允許的狀態做更正；叫號操作若有提供「還原上一步」，可用來修正上一個動作。保留候位會依店家的保留規則恢復原順位或放到隊尾，號碼本身不變。

重置預約號碼或叫號號碼，舊資料會消失嗎？

不會。兩套流水號各自重置，新的一筆從 1 開始，已建立的預約／號碼牌及永久識別碼仍保留。重置與更改前綴需具管理權限。

為什麼搜尋店家找不到我的門市？

請確認門市已完成基本資料、目前處於啟用狀態，並在「設定」開啟公開搜尋。沒有公開搜尋時，已註冊門市仍可用自己的專屬網址分享。

顧客已經登入 LINE，為什麼沒收到通知？

LINE 身分驗證與加入官方帳號好友不同。請先確認顧客是否加入對應官方帳號、未封鎖，以及平台訊息通知的發送資格／狀態。若使用自有 LINE 官方帳號，也請確認通知設定與手機收訊功能正常。

可以用手機操作後台嗎？

可以。商家管理後台支援手機和電腦瀏覽器；預約管理、叫號管理與狀態修正都可在手機開啟。建議將店家後台網址加入手機書籤，以便現場使用。

忘記怎麼設定，或操作發生問題，要找誰？

先查看本頁對應章節，再將遇到問題的功能名稱、操作時間及錯誤畫面告知平台客服。不要提供密碼、LINE 官方帳號驗證金鑰或其他機密憑證。

準備開始操作？

已註冊的店家直接進後台；新商家先註冊店家帳號。
