正式介面樣式對照｜設定中的 LINE 官方帳號串接（僅使用範例資料）

店家管理者操作

建立 Messaging API，取得必要兩項資料

  1. 開啟 LINE 官方帳號管理後台，選擇店家的官方帳號；沒有官方帳號請先建立。
  2. 在官方帳號後台「設定」→「Messaging API」啟用 Messaging API，並選擇或建立 Provider。已有店家 OA 就在既有帳號啟用，不需要重辦一個。
  3. 開啟 LINE Developers Console，選擇相同 Provider 下對應的 Messaging API channel。
  4. 在「Basic settings」找到 Channel secret 並複製。
  5. 在「Messaging API」頁籤找到 Channel access token (long-lived)，按「Issue」取得長效憑證。Channel ID 不需要填寫，系統會驗證 Token 後自動取得。
  6. 回到排隊怪獸「設定」→「LINE 官方帳號串接」，貼上這兩個值，按「驗證並連接 Messaging API」。單純發送推播不需要先建立 LINE Login／LIFF。
  7. 把排隊怪獸後台產生的 Webhook URL 複製到 LINE Developers → Messaging API → Webhook URL，開啟「Use webhook」並按「Verify」。
  8. 用真實手機加入店家 OA 好友並發送訊息，確認 Webhook 能接到事件；再實測預約／抽號通知是否可到達。只驗證 Token 不代表推播已驗收成功。

需要店家專屬 LINE 登入時才加做：在同一 Provider 建立 LINE Login channel，選 LIFF 頁籤建立 LIFF App，再回排隊怪獸進階設定填 LIFF ID。若使用平台 LINE Login 而店家 OA 位於不同 Provider，顧客的 User ID 不會自動相同，必須另外完成身分配對。

LINE 官方 Messaging API 建立教學 ↗ ・ LINE 官方 LIFF 教學（進階選用） ↗

08

店家最常遇到的問題

不用翻技術文件；依實際操作情境查找。

我沒有自己的 LINE 官方帳號，也能讓顧客預約嗎？

可以。完成註冊及門市基本設定後，可使用平台共用 LINE 官方帳號接待顧客。顧客可從平台的店家搜尋入口，或直接掃店家專屬 QR Code／點分享網址進行預約或取號。

預約已報到，為什麼沒有自動進入叫號？

預約與取號預設為獨立流程。若門市尚未設定場次連動，報到只會更新預約狀態；需要現場叫號時，可另行取號。

客人過號、按錯，或要恢復候位怎麼辦？

到「叫號管理」找到該號碼牌，依目前允許的狀態做更正；叫號操作若有提供「還原上一步」，可用來修正上一個動作。保留候位會依店家的保留規則恢復原順位或放到隊尾，號碼本身不變。

重置預約號碼或叫號號碼，舊資料會消失嗎？

不會。兩套流水號各自重置，新的一筆從 1 開始，已建立的預約／號碼牌及永久識別碼仍保留。重置與更改前綴需具管理權限。

為什麼搜尋店家找不到我的門市？

請確認門市已完成基本資料、目前處於啟用狀態，並在「設定」開啟公開搜尋。沒有公開搜尋時，已註冊門市仍可用自己的專屬網址分享。

顧客已經登入 LINE，為什麼沒收到通知？

LINE 身分驗證與加入官方帳號好友不同。請先確認顧客是否加入對應官方帳號、未封鎖，以及平台訊息通知的發送資格／狀態。若使用自有 LINE 官方帳號，也請確認通知設定與手機收訊功能正常。

可以用手機操作後台嗎？

可以。商家管理後台支援手機和電腦瀏覽器；預約管理、叫號管理與狀態修正都可在手機開啟。建議將店家後台網址加入手機書籤，以便現場使用。

忘記怎麼設定，或操作發生問題，要找誰？

先查看本頁對應章節，再將遇到問題的功能名稱、操作時間及錯誤畫面告知平台客服。不要提供密碼、LINE 官方帳號驗證金鑰或其他機密憑證。

準備開始操作？

已註冊的店家直接進後台；新商家先註冊店家帳號。
