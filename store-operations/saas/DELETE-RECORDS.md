# 店家刪除預約與號碼牌

店員「預約管理」「叫號管理」每筆資料有刪除勾選框。勾選會呼叫 `so_staff_set_record_deleted`，資料以 `deleted_at` 保留在資料庫並記入稽核，不是取消狀態，亦不產生 LINE 通知。已刪除紀錄在店員後台單獨列出，取消勾選可恢復。

顧客 `so_public_state`、我的店家紀錄、有效預約容量、叫號佇列與平台統計都會排除已刪除記錄。預約已報到者會連同對應號碼一起隱藏，恢復預約時只恢復因該次刪除而連動隱藏的號碼。保留原始號碼避免重號。

LINE Edge Function 查詢預約及號碼時也排除 `deleted_at IS NOT NULL`，避免被刪除的紀錄仍能呼叫推播。已發出的 LINE 訊息無法撤回。
