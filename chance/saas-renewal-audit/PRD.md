# PRD｜企業 SaaS 續費與閒置席次盤點

> 版本：v0.1（2026-11-03）｜產品編號：20261024-008｜狀態：已實作瀏覽器單機 MVP，尚未完成正式商業營運部署及付款驗證。

## 1. 產品定位與市場依據

- **目標客戶**：中小企業及營運／採購負責人
- **原始商機**：20261024-008，評分 80，來源 Google 試算表「機會」。
- **來源資料**：https://docs.google.com/spreadsheets/d/103uxu5VmnDj7WBrByD9vjpLgauy8-M6uZXqDSnWk7tI/edit?gid=1377271577
- **實際痛點**：員工未使用的工具與重複授權在續約時被默默扣款。
- **選題理由**：可以直接找出浪費席次及即將續訂的合約，易量化節省。
- **定價假設**：NT$6,500／次診斷（假設）。並非已驗證的付費意願或現有銷售。

## 2. 用戶流程（本次已實作）

1. 打開獨立網址：https://hub-google.github.io/Chance/saas-renewal-audit/
2. 不需登入，新增紀錄，填寫「服務名稱、席次、有效席次、月單價、續約日期、通知天數」。
3. 儲存後立即計算、顯示狀態與警示，支援搜尋、編輯、刪除。
4. 匯出 CSV、下載完整 JSON 備份、JSON 還原，以及列印／存成 PDF。
5. 資料留在該瀏覽器的 localStorage；非無伺服器多人版本。

## 3. 核心計算與規則

預估閒置月費＝max(席次－使用席次,0)×單價；續約警戒按日期

系統提供即時計算與可視化警示，不能把估算值當成平台、銀行或官方核定資料。

## 4. MVP 功能與範圍

**實作範圍**：訂閱費盤點、閒置席次估算、續約提醒、年度浪費試算、匯出；響應式電腦／手機介面、資料輸入驗證、清單搜尋與排序（最新資料優先）、批次 CSV 輸出、JSON 備份與恢復、列印友善檢視。

**未實作**：會員、跨裝置同步、後端資料庫、角色權限、付款扣款／訂閱續費、自動推播通知、外部系統串接、檔案附件存放、收據或正式電子簽署。相關項目不應在行銷上宣稱已具備。

## 5. 資料欄位

| 欄位 | 型態 |
| --- | --- |
| 服務名稱 | 文字 |
| 訂閱席次 | 非負數字 |
| 實際使用席次 | 非負數字 |
| 每席月費（NT$） | 非負數字 |
| 下次續約日 | YYYY-MM-DD |
| 提前提醒天數 | 非負數字 |

## 6. 營利模式與驗證

- 定價：NT$6,500／次診斷（假設），僅根據原始研究的假設。
- 最低驗證：以真實目標客戶訪談至少 10 位；提供現有 MVP 的可用連結；確認至少 3 位願意付費試用，並蒐集節省工時與留存意願。
- 轉成可營利 SaaS 前：加入會員與租戶隔離、資料庫與定期備份、台灣個資與服務條款處理、正式金流、訂閱權限與管理後台、觀測/故障通知。
- 建議推廣渠道：中小企業及營運／採購負責人的相關專業社群、產業協會與示範案例內容；避免把未驗證需求說成已成交。

## 7. 風險與限制

價格與使用數字為用戶輸入，不會擷取銀行或 SaaS 平台帳號。

- 使用者自行輸入資料，系統不驗證法律、會計、投標、設備或交易事實。
- 本機存放可能因清除網站資料而遺失；跨裝置無法共用；多人使用前必須導入可稽核的後端。
- 一律不在 Git 倉庫保留 API 密鑰、個資或客戶真實交易檔案。

## 8. 驗收標準

1. 使用者可在手機或桌機新增紀錄，重新整理後仍存在（同一瀏覽器、未清除網站資料）。
2. 修改數值會重新計算且 UI 當下更新，異常資料可顯示風險提示。
3. 可搜尋、修改、刪除紀錄；刪除需二次確認。
4. 匯出 CSV 可在試算表開啟；同產品 JSON 備份能在另一瀏覽器環境還原。
5. 不會自動發出或假稱已發出金流、通知、合法文件、官方證明。
6. 個別網址可直接開啟而不依賴首頁導航。
