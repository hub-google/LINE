# PRD｜公共工程開口契約額度控管

> 版本：v0.1（2026-11-03）｜產品編號：20261028-009｜狀態：已實作瀏覽器單機 MVP，尚未完成正式商業營運部署及付款驗證。

## 1. 產品定位與市場依據

- **目標客戶**：台灣工程技術顧問及小型承包商
- **原始商機**：20261028-009，評分 79，來源 Google 試算表「機會」。
- **來源資料**：https://docs.google.com/spreadsheets/d/103uxu5VmnDj7WBrByD9vjpLgauy8-M6uZXqDSnWk7tI/edit?gid=1377271577
- **實際痛點**：同一開口契約有多筆派工，累計支用及待核銷金額容易超出餘額。
- **選題理由**：資料模型明確，能依契約編號加總派工金額及剩餘額度。
- **定價假設**：NT$4,500／月（假設）。並非已驗證的付費意願或現有銷售。

## 2. 用戶流程（本次已實作）

1. 打開獨立網址：https://hub-google.github.io/Chance/contract-work-orders/
2. 不需登入，新增紀錄，填寫「契約代號、派工編號、契約上限、已核銷金額、待核銷金額、期限」。
3. 儲存後立即計算、顯示狀態與警示，支援搜尋、編輯、刪除。
4. 匯出 CSV、下載完整 JSON 備份、JSON 還原，以及列印／存成 PDF。
5. 資料留在該瀏覽器的 localStorage；非無伺服器多人版本。

## 3. 核心計算與規則

同契約剩餘額＝契約上限－所有派工核銷與待核銷合計

系統提供即時計算與可視化警示，不能把估算值當成平台、銀行或官方核定資料。

## 4. MVP 功能與範圍

**實作範圍**：多契約派工清冊、總額預警、個別進度、CSV 匯出與列印；響應式電腦／手機介面、資料輸入驗證、清單搜尋與排序（最新資料優先）、批次 CSV 輸出、JSON 備份與恢復、列印友善檢視。

**未實作**：會員、跨裝置同步、後端資料庫、角色權限、付款扣款／訂閱續費、自動推播通知、外部系統串接、檔案附件存放、收據或正式電子簽署。相關項目不應在行銷上宣稱已具備。

## 5. 資料欄位

| 欄位 | 型態 |
| --- | --- |
| 契約代號 | 文字 |
| 派工編號／內容 | 文字 |
| 契約核定總額（NT$） | 非負數字 |
| 本派工已核銷（NT$） | 非負數字 |
| 本派工待核銷（NT$） | 非負數字 |
| 履約期限 | YYYY-MM-DD |
| 派工狀態 | 選單：待辦|執行中|已完成 |

## 6. 營利模式與驗證

- 定價：NT$4,500／月（假設），僅根據原始研究的假設。
- 最低驗證：以真實目標客戶訪談至少 10 位；提供現有 MVP 的可用連結；確認至少 3 位願意付費試用，並蒐集節省工時與留存意願。
- 轉成可營利 SaaS 前：加入會員與租戶隔離、資料庫與定期備份、台灣個資與服務條款處理、正式金流、訂閱權限與管理後台、觀測/故障通知。
- 建議推廣渠道：台灣工程技術顧問及小型承包商的相關專業社群、產業協會與示範案例內容；避免把未驗證需求說成已成交。

## 7. 風險與限制

不會自動讀標案、不會代為判定採購法規或正式核銷資格。

- 使用者自行輸入資料，系統不驗證法律、會計、投標、設備或交易事實。
- 本機存放可能因清除網站資料而遺失；跨裝置無法共用；多人使用前必須導入可稽核的後端。
- 一律不在 Git 倉庫保留 API 密鑰、個資或客戶真實交易檔案。

## 8. 驗收標準

1. 使用者可在手機或桌機新增紀錄，重新整理後仍存在（同一瀏覽器、未清除網站資料）。
2. 修改數值會重新計算且 UI 當下更新，異常資料可顯示風險提示。
3. 可搜尋、修改、刪除紀錄；刪除需二次確認。
4. 匯出 CSV 可在試算表開啟；同產品 JSON 備份能在另一瀏覽器環境還原。
5. 不會自動發出或假稱已發出金流、通知、合法文件、官方證明。
6. 個別網址可直接開啟而不依賴首頁導航。
